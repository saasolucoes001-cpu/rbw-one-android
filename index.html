RBW One para Android

Acesse a versão mobile do RBW One pelo aplicativo Android.

Baixar APK — versão 1.0.0

Compatível com Android 6 ou superior. É necessário ter um navegador compatível e conexão com a internet. O acesso às informações continua protegido pelo login do RBW One.

Atualizações

O APK consulta este canal ao abrir. Quando houver uma versão nova compatível, o download é automático. A instalação depende da confirmação solicitada pelo próprio Android.

As atualizações das telas continuam sendo publicadas no aplicativo web. Não é necessário reinstalar o APK para cada alteração do site.

Este canal é independente do projeto web. Distribui apenas instaladores e metadados de versão, sem dados dos usuários.
